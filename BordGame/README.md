# PRISON LAB：第17号更生実験

PCを中央監視画面、1〜4台のスマートフォンを囚人用の個人端末として使う、リアルタイム監獄心理戦ボードゲームです。不足人数は最大3人のCPUで補えます。4日間の心理実験で協力と裏切りを繰り返し、評価上位での釈放、または秘密の脱獄を目指します。

## 必要環境

- Node.js 20以降（Node.js 22 LTS推奨）
- npm
- ホストPCと各スマートフォンが接続された同一Wi-Fi／LAN
- モダンブラウザ（Chrome、Edge、Safari、Firefoxの現行版）

ゲーム状態はサーバーのメモリにのみ保存します。サーバーを終了すると進行中のルームは失われます。

## インストールと起動

プロジェクトディレクトリで次を実行します。

```bash
npm install
npm start
```

起動後：

```text
Host:
http://localhost:3000/host

Player:
http://localhost:3000/
```

開発中は `npm run dev` でNode.jsのwatchモードを利用できます。

## 遊び方

1. ホストPCで `http://localhost:3000/host` を開き、「実験室を作成」を押します。
2. 中央画面に表示されたQRコードを各スマートフォンで読み取ります。
3. 各プレイヤーが名前を入力して参加します。人数が足りない場合は、ホスト画面の「CPUを追加」で最大3人まで補います。
4. 4人が揃ったらホストが「ゲーム開始」を押します。
5. 中央画面の看守放送と説明に従い、スマートフォンで秘密の回答を確定します。
6. 全員回答後、ホストが「次のフェーズへ」で結果を公開します。
7. 4日目の最終審査まで進め、釈放または脱獄の勝者を決定します。

スマートフォンから接続できない場合は、全端末が同じWi-Fiにいることを確認してください。Windows Defender ファイアウォールの確認画面が出た場合、プライベートネットワークでNode.jsの通信を許可する必要があります。PCに複数のネットワークアダプターがある場合は、ホスト画面の「URLを変更」から実際のLAN IP（例：`http://192.168.1.20:3000`）を指定するとQRコードが更新されます。

## ゲームルール概要

- 全4日、4人固定です。
- 人間1人＋CPU3人から人間4人まで遊べます。CPUは心理実験、夜間行動、脱獄判断、阻止行動を自動選択します。
- 個人評価は0〜100、ストレスと疑惑度は0〜10、監獄秩序は0〜100です。
- 中央画面は評価順位と評価区分のみ公開し、正確な個人値、手札、未公開回答、夜間行動、脱獄者を表示しません。
- 1日目は囚人のジレンマ、2日目は配給食実験、3日目は赤白帽子実験、4日目は2段階の信頼投資実験です。
- 心理実験後は、休息、物資探索、密告、観察、カード譲渡などの夜間行動を秘密裏に選択します。
- 各プレイヤーは初期手札2枚を持ち、準備または夜間に1日1枚まで通常効果で使用できます。
- 2日目終了後、条件を満たした低評価の囚人には秘密の脱獄ルートが提示されます。脱獄計画者はカードで「経路」「突破手段」「タイミング」を準備します。
- 脱獄がなければ、疑惑度8以上の最終補正（評価−15）を適用後、上位2名が勝利します。
- 脱獄時は残る3名が阻止行動を選び、脱獄力が阻止力を上回れば脱獄者だけが勝利します。同点は阻止成功です。

画面の「制限時間開始」でカウントダウンを開始できます。0秒になると未回答へ規定の既定値が設定されますが、結果公開や次フェーズへの移行はホスト操作のままです。

## 再接続

参加時のルームコード、プレイヤーID、セッショントークン、表示名はブラウザの `localStorage` に保存されます。同じブラウザでプレイヤー画面を再度開くと自動再接続します。切断したプレイヤーはサーバーから即時削除されず、中央画面には「一時切断」「再接続済み」が表示されます。ホストも同じブラウザなら自動再接続します。

## デバッグモード

次のURLだけでデバッグパネルを表示します。

```text
http://localhost:3000/host?debug=1
```

全プレイヤーの内部値と回答の確認、評価・ストレス・疑惑度・秩序の変更、カード付与、脱獄提案、計画者指定、日数・フェーズ変更、既定回答の自動入力、最終脱獄へのスキップができます。通常のホスト画面には内部情報も操作パネルも送信・表示されません。

## テスト

```bash
npm test
```

Node.js標準の `node:test` で、数値制限、4種の心理実験、脱獄力と阻止力、監獄秩序ボーナス、情報保護を検証します。

## 主な構成

```text
server.js                 Express / Socket.IO / QR / タイマー
src/game/gameEngine.js    フェーズ進行と最終判定
src/game/minigames.js     4種の心理実験
src/game/nightActions.js  夜間行動と日末処理
src/game/cards.js         山札とカード効果
src/game/escape.js        脱獄・阻止力
src/game/serializers.js   公開・ホスト・本人用の情報分離
public/host.html          中央監視画面
public/player.html        スマートフォン個人端末
tests/                    自動テスト
```

## 現在の制限

- 4人固定で、途中参加や観戦には対応していません。
- ルームおよび再接続情報は永続化されません。サーバー再起動後は新しい実験室を作成してください。
- Tailwind CSSはMVP要件に合わせCDN版を利用しています。インターネットに接続できない環境でも独自CSSで主要操作は可能ですが、一部のレイアウト装飾が簡素になります。
- 音声はブラウザの自動再生ポリシーにより鳴らない場合があります。判定と進行には影響しません。
- 単一Node.jsプロセスのメモリ管理を前提とし、インターネット越しの公開運用や複数サーバー構成は対象外です。

## 将来の拡張
